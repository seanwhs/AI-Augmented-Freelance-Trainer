# The AI-Augmented Freelance Trainer — GitHub Pages Website

This folder contains a ready-to-host static website built for **GitHub Pages**.

## Files Included
- `index.html` — Full playbook and interactive 16-prompt library
- `styles.css` — Typography, light/dark theme variables, and animations
- `app.js` — Phase filtering, keyword search, one-click prompt copy, reading progress, and navigation highlight
- `.nojekyll` — Ensures GitHub Pages serves files directly without Jekyll processing

## How to Publish on GitHub Pages
1. Create a new repository on GitHub (for example, `ai-trainer-playbook`).
2. Upload `index.html`, `styles.css`, `app.js`, and `.nojekyll` to the root of the repository (or push via Git).
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment → Source**, select **Deploy from a branch**.
5. Choose your branch (usually `main`) and folder (`/ (root)`), then click **Save**.
6. Wait 1–2 minutes for your live URL (`https://<your-username>.github.io/<repo-name>/`) to become active.
