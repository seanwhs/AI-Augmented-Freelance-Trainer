## ✨ What This Is

This is a polished, editorial-style web edition of the full playbook:

- **Part I — The Roadmap to Paid Bookings** — Niche → Signature IP → Keynote Engine → Channel → Founding Circle → Lean Ops

- **Part III — The Business** — Your price is set before you say a number
- **Part IV — The AI Operating System** — Master Prompt Library (15 copy-ready prompts)
- **30-Day Launch Sprint** — Clarity → Build → Prove → Sell

Nothing is summarized or cut. Every section, table, prompt, and example from the original playbook is preserved — only the presentation is upgraded with diagrams, cards, and visual hierarchy.

## 🚀 How to Use It

### Option 1: Open It Locally (Fastest)

1. Download the `.html` file
2. Double-click it — it opens in any modern browser
3. Read, scroll, and use the sticky navigation to jump between Parts I–IV

No server, install, or internet connection needed.

### Option 2: Host It as a Static Site (Free)

Upload the single `.html` file to any static host:

- **GitHub Pages** — Drop it in a repo → Settings → Pages → Deploy from branch
- **Netlify Drop** — Drag the file onto [app.netlify.com/drop](https://app.netlify.com/drop)
- **Vercel** — `vercel` → upload the file
- **Cloudflare Pages** — Create project → upload the file
- **Any web host / S3 / Google Drive preview** — Upload and share the link

Rename it to `index.html` if you want it to load as the homepage of a folder/site.

### Option 3: Use the Markdown Version

Open `AI-Augmented-Freelance-Trainer-Playbook.md` in:

- **Obsidian** — Mermaid diagrams render natively
- **Notion** — Import → Markdown (Mermaid blocks import as code — paste them into a Mermaid embed if needed)
- **GitHub** — Preview renders tables + Mermaid automatically
- **VS Code** — Install the Markdown Preview Mermaid Support extension

## ✏️ How to Customize It

The HTML file is plain, human-readable HTML + CSS. No framework, no build tools.

| Want to change... | Do this... |
| :--- | :--- |
| **Title / subtitle** | Search for the `<h1>` in the hero section |
| **Your name / bio** | Add it under the hero subtitle, or in the footer |
| **Colors** | Edit the CSS variables at the top of `<style>` — background, accent, heading colors |
| **Your niche example** | Replace the engineering-manager example in Part I, Section 1 with your own |
| **Your framework name** | Replace *The Clarity Loop / The 4-Gate Review* with your framework name |
| **Your price** | Replace the `$8,500` example in Part III with your own anchor |
| **Add a CTA** | Add a button/link in the footer — e.g. “Book a Discovery Call” → your booking link |
| **Add testimonials** | Add a testimonial card section after Part I, Section 5 |

> **Tip:** Make a copy before editing, so you always have the pristine original.
